# Bank Management System

A simple **Bank Management System** built with HTML, CSS, and JavaScript. It simulates real-world banking operations for multiple users.

## Features

- Create multiple bank accounts
- Deposit and withdraw money
- Transfer funds between accounts
- Track detailed transaction history for each account
- Persistent data storage using **localStorage**
- Inputs clear automatically after each operation
- Real-time balance and transaction updates

## Technologies

- HTML
- CSS
- JavaScript (OOP concepts used)
- localStorage for data persistence
